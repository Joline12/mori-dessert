# Mori 食光研究所｜手機展示版

此版本已移除「鳳梨酥小禮盒」與「柚香氣泡飲」，避免這兩項商品圖片持續顯示異常。其餘甜點、分類、搜尋、購物車、優惠券與模擬結帳功能保留。

## 手機開啟
1. 解壓縮 ZIP。
2. 開啟資料夾中的 `index.html`，選擇使用 Chrome 開啟。

本版本將 CSS 與 JavaScript 內嵌於 `index.html`，所以不需要額外的 `style.css` 或 `script.js`。README 是操作說明檔，網站只需 `index.html` 即可運作。

商品圖片（除內嵌的圖片以外）需要網路連線。此網站為前端展示版，結帳為模擬流程，沒有連接真實付款或訂單資料庫。


本版本已將改為內嵌 PNG 圖片，與奶油可頌使用不同圖片；不需額外圖片檔。
